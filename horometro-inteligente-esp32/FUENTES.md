# Fuentes y dependencias

## Documentación de referencia

- Arduino IDE: https://www.arduino.cc/en/software
- Arduino-ESP32 (Espressif): https://docs.espressif.com/projects/arduino-esp32/en/latest/
- Preferences/NVS: https://docs.espressif.com/projects/arduino-esp32/en/latest/api/preferences.html
- BLE de Arduino-ESP32: https://github.com/espressif/arduino-esp32/tree/master/libraries/BLE
- pySerial: https://pyserial.readthedocs.io/en/latest/
- Python http.server: https://docs.python.org/3/library/http.server.html
- phyphox, BLE: https://phyphox.org/docs/file-format/bluetooth-low-energy/
- phyphox, transferencia: https://phyphox.org/docs/transferring-experiments/
- phyphox, salida de audio: https://phyphox.org/docs/file-format/output/
- OpenSCAD: https://openscad.org/documentation.html
- Home Assistant en Windows (opcional): https://www.home-assistant.io/installation/windows/
- Home Assistant Local Push (opcional): https://companion.home-assistant.io/docs/notifications/notification-local/

Entorno de carga confirmado por el usuario: Arduino IDE 2.3.11 y paquete esp32 3.3.12; Python requiere 3.10+ y pyserial>=3.5,<4. No instalar la antigua biblioteca BLE independiente sobre la incluida en el paquete Espressif.

## Elaboración y uso de IA
